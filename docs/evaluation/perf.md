# Performance evaluation

## Acceptance targets

- Time-to-Guidance: ≤ 15 seconds
- Time-to-Call: ≤ 45 seconds

These targets are not claimed as measured until a Playwright run records them on a throttled 4G profile and offline mode. The repository currently has build and unit-test evidence, but no checked-in device-emulation measurements. Add the command, viewport/device profile, date, and raw result before marking this section complete.
